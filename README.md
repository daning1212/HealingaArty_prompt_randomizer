# 🎲 HealingArty Prompt Randomizer · Library

프롬프트를 카테고리별로 보관하고, 선택한 헤어·표정·의상·포즈를 합쳐 출력하는 ComfyUI 노드입니다.

이 안내는 현재 **Library v1.0.4** 기준입니다. 노드 검색에서 **🎲 HealingArty Prompt Randomizer · Library**를 선택하세요.

![HealingArty Prompt Library 레이아웃 시안](docs/prompt-library-layout.webp)

> AI로 제작한 레이아웃 시안입니다. 실제 실행 화면 캡처가 아니며, 현재 UI의 메뉴·배치·문구와 차이가 있습니다.

## 설치 및 업데이트

ComfyUI의 `custom_nodes` 폴더에서 설치합니다.

```cmd
git clone https://github.com/daning1212/HealingaArty_prompt_randomizer.git
```

업데이트는 설치된 `HealingaArty_prompt_randomizer` 폴더에서 실행합니다.

```cmd
git pull
```

**ComfyUI 재시작 → 브라우저 Ctrl+F5** 후 사용하세요. 기존 Library 노드는 그대로 사용할 수 있습니다.

## 먼저 사용해 보기

1. 노드 검색에서 **HealingArty Prompt Randomizer · Library**를 추가합니다.
2. 아래 **프롬프트 보관함**의 편집창에 기본 프롬프트를 입력합니다.
3. 위에서 헤어·표정·의상 등 필요한 항목을 선택합니다.
4. 포즈를 사용하려면 **자세 유형 → 포즈** 순서로 선택합니다.
5. `positive_prompt` 출력을 워크플로의 텍스트 입력에 연결하고 ComfyUI에서 생성을 실행합니다.

가운데 **최종 출력**에는 실제 실행에서 합쳐진 프롬프트가 표시됩니다. 메뉴 선택이나 저장만으로 생성을 시작하지 않습니다.

## 화면 구성

| 영역 | 기능 |
| --- | --- |
| 위쪽 선택 메뉴 | 헤어·표정·의상·신발·가방 등 필요한 항목 선택 |
| 자세 유형 / 포즈 | 서기·앉기·눕기 중 하나를 고른 뒤 세부 포즈 선택 |
| 액세서리 더 보기 | 안경·모자·화장·팬티스타킹 선택 |
| 시드 / 시드 모드 | 랜덤 결과를 매번 바꾸거나 고정 |
| 고급 설정 · 가중치 | 선택한 문구의 강조값 조절 |
| 최종 출력 | 마지막 실행에서 합쳐진 프롬프트 확인·복사 |
| 프롬프트 보관함 | 카테고리와 이름별로 문구 저장·검색·불러오기·수정·삭제 |

프롬프트 입력창은 아래 보관함에 하나만 있습니다. 입력창과 최종 출력창은 높이를 조절할 수 있으며 긴 내용은 내부 스크롤로 확인합니다. 노드를 작게 줄이면 노드 내부도 스크롤됩니다.

## 선택 방식과 포즈

| 선택값 | 동작 |
| --- | --- |
| none | 해당 항목을 출력하지 않음 |
| random | 실행 시 무작위로 선택 |
| 순차 | 실행할 때마다 다음 항목으로 이동하고 끝에서 처음으로 순환 |
| 직접 선택 | 선택한 문구를 고정 출력 |

각 메뉴를 독립적으로 설정합니다. 예를 들어 헤어는 직접 선택, 표정은 random, 포즈는 순차로 사용할 수 있습니다.

**포즈가 비활성화되어 있으면 먼저 자세 유형을 선택하세요.** 자세 유형이 `none`이면 포즈 메뉴가 잠깁니다. `서기 / 앉기 / 눕기` 중 하나를 고르면 해당 포즈 목록이 열립니다. 유형을 바꾸면 포즈 선택은 `none`으로 돌아가므로 다시 선택하세요.

현재 포즈 목록은 서기 85종, 앉기 69종, 눕기 56종입니다. 한 번에 한 자세 유형만 사용합니다.

**전체 해제**는 선택 메뉴와 자세를 `none`으로 바꿉니다. 편집 문구·저장 목록·시드·가중치와 순차 진행 위치는 유지합니다.

## 시드와 가중치

- **자동:** 실행할 때마다 새 시드를 사용합니다.
- **고정:** 같은 시드와 같은 입력이면 같은 랜덤 선택을 재현합니다.
- **시드 -1:** 모드와 관계없이 새 시드를 사용합니다.
- **순차:** 시드와 관계없이 실행할 때마다 다음 항목으로 이동합니다.

순차 위치는 실행 중 노드 메모리에 저장됩니다. ComfyUI를 재시작하거나 노드를 새로 만들면 처음부터 시작합니다. 노드 한 번 실행당 한 단계 진행하며 이미지 배치 안의 이미지마다 바뀌지는 않습니다.

가중치는 선택 확률이 아닌 출력 문구의 강조값입니다. 예를 들어 1.2이면 `(smiling:1.2)`로 출력하고, 1.0이면 일반 문구로 출력합니다. 실제 해석은 연결한 인코더·모델에 따라 다릅니다.

## 프롬프트 저장과 불러오기

예: **게임 → 테리 보가드**

1. **+ 카테고리 추가**에서 `게임`을 만듭니다.
2. **+ 새 프롬프트**를 누르고 이름과 프롬프트를 입력합니다.
3. **프롬프트 저장**을 눌러 저장창에서 카테고리와 이름을 확인합니다.
4. 다음에는 카테고리와 저장 목록에서 해당 항목을 선택하면 편집창에 불러옵니다.

| 버튼 | 동작 |
| --- | --- |
| + 새 프롬프트 | 새 문구 작성 |
| 수정 | 불러온 문구를 편집할 수 있도록 전환 |
| 프롬프트 저장 | 새 항목을 저장하거나 현재 항목의 수정 내용 저장 |
| 이름 변경 | 선택한 항목의 저장 이름 변경 |
| 프롬프트 삭제 | 확인 후 선택한 항목 삭제 |
| + 카테고리 추가 | 새 카테고리 생성 |
| 카테고리 삭제 | 내부 프롬프트 개수를 안내하고 확인 후 카테고리와 내부 항목 삭제 |
| 새로고침 | 서버의 저장 목록 다시 읽기 |

같은 카테고리에서 같은 이름으로 새 항목을 만들면 덮어쓰지 않고 안내합니다. 검색은 프롬프트 이름과 내용을 대상으로 합니다. 카테고리 이름 변경 기능은 제공하지 않습니다.

저장하지 않은 편집 내용이 있을 때 다른 항목으로 이동하면 확인합니다. **편집 중인 문구는 다음 생성에 사용되지만, 보관함의 저장 항목을 갱신하려면 저장 버튼을 눌러야 합니다.**

보관함에는 **이름·카테고리·프롬프트 문구**를 저장합니다. 랜덤 메뉴 설정 전체를 저장하는 프리셋은 아닙니다. 프롬프트를 삭제해도 현재 편집창의 문구는 남습니다.

## 연결과 최종 출력

선택적인 `text_in` 입력에 외부 텍스트 노드를 연결할 수 있습니다. 최종 프롬프트는 다음 순서로 합칩니다.

**외부 text_in → 아래 편집창 문구 → 선택 메뉴의 결과**

| 출력 | 내용 |
| --- | --- |
| positive_prompt | 합쳐진 최종 프롬프트 |
| 세부사항 | 시드·선택 문구·순차 순번 |
| 사용된_시드 | 실제 사용한 시드 |

가운데 최종 출력창은 `positive_prompt`와 같은 내용을 보여주며 **생성 실행 후 갱신**됩니다. 설정만 바꾸면 이전 실행 결과가 남아 있을 수 있습니다. 편집 문구가 비어 있고 모든 선택이 `none`이면 빈 문자열을 출력합니다.

원문에 이미 의상·자세가 있으면 선택 결과와 충돌할 수 있으므로 문구를 확인하세요. 포즈 반영 정도와 태그·가중치 해석은 모델에 따라 다릅니다. 원본 자세를 교체하는 별도 지시문이나 자동 번역 기능은 없습니다.

## 저장 위치와 백업

보관함은 ComfyUI 실행 컴퓨터의 다음 파일에 저장합니다.

```text
user/default/healingarty_prompt_library.json
```

ComfyUI 사용자 폴더를 따로 지정했다면 그 폴더 아래의 `default` 경로를 사용합니다. 여러 Library 노드와 워크플로가 같은 보관함을 공유합니다. 단일 사용자 로컬 환경 기준이며 계정별 보관함 분리는 제공하지 않습니다.

저장할 때 이전 파일은 `healingarty_prompt_library.json.bak`로 보관합니다. 다른 창에서 동시에 수정한 경우 오래된 목록으로 덮어쓰지 않고 새로고침을 안내합니다. 잘못된 JSON 파일을 자동 초기화하지 않습니다.

다른 PC로 옮길 때는 ComfyUI를 종료하고 JSON 파일을 복사하세요. 워크플로에도 현재 편집 문구와 선택 설정이 저장되므로, 다른 PC에 보관함 파일이 없어도 현재 문구로 생성할 수 있습니다.

외부 Prompt Manager의 저장 파일을 자동으로 가져오는 기능은 없습니다.

## 현재 Library에 없는 기능

분위기·배경·소품 메뉴, 촬영 인원·단체 포즈, 이미지방향 선택, 의상제거 스위치는 현재 Library UI에서 제공하지 않습니다. 필요한 문구는 아래 프롬프트 편집창에 직접 작성할 수 있습니다.

기존 V11의 촬영 인원·단체 포즈 등은 Library 기능이 아닙니다. 이 README의 사용 순서와 보관함 설명은 Library 기준입니다.
